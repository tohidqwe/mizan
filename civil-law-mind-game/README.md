# بازی ذهنی مدنی ۳

MVP مستقل برای تبدیل مواد ۱۸۳ تا ۲۳۲ قانون مدنی به بازی لمسی و بصری.

## اصل محصول
کاربر قبل از دیدن پاسخ، با انگشت ساختار حقوقی را **می‌سازد**:
- Drag & Drop روی شاخه درست
- اتصال گره‌ها با کابل لمسی
- مونتاژ معامله در Contract Lab
- چیدن زنجیره شرط ← حکم ← اثر

متن رسمی ماده بعد از حل مرحله نمایش داده می‌شود تا ساختار ساخته‌شده در ذهن به متن قانون قفل شود.

## استقلال
این پروژه applicationId و پوشه مستقل دارد:
`ir.madani3.mindgame`

هیچ فایل پروژه «حافظ قانون» یا «درخت قانون مدنی» را تغییر نمی‌دهد.

## محدوده MVP
۵۰ ماده: ۱۸۳ تا ۲۳۲ قانون مدنی.
متن رسمی در CI مستقیماً از Qavanin.ir دریافت و قبل از Build ممیزی می‌شود.
