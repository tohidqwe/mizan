# درخت قانون مدنی

محصول مستقل و تجاری «درخت قانون مدنی» برای آموزش دانشگاهی حقوق مدنی ایران با محور قانون رسمی، Mind Map، Knowledge Graph و مسیرهای مدنی ۱ تا ۸.

## اصل جداسازی
این پروژه هیچ وابستگی کدی، دیتابیسی یا اجرایی به اپ قبلی «حافظ قانون مدنی» ندارد. applicationId، دیتابیس، assets، workflow و backend مستقل هستند.

## منبع قانون
متن مواد در CI مستقیماً از صفحه رسمی Qavanin.ir دریافت می‌شود و پیش از Build روی شماره‌گذاری، یکتایی و منبع ممیزی می‌شود. متن رسمی از تحلیل آموزشی جدا نگهداری می‌شود.

## وضعیت محتوای علمی
- متن رسمی: OFFICIAL_QAVANIN
- طبقه‌بندی و Mind Map خودکار: AI_DRAFT / NEEDS_LEGAL_REVIEW
- دیدگاه استادان: فقط پس از ثبت منبع و Legal Review قابل انتشار
- Production release باید فقط محتوای APPROVED را نمایش دهد.

## اجزا
- `android/`: اپ Android مستقل با Jetpack Compose
- `tools/`: دریافت متن رسمی و ساخت Knowledge Graph/Mind Map
- `backend/`: API تولیدی برای حساب، مجوز، اشتراک، محتوا، versioning و audit
- `admin/`: پنل مدیریت محتوا و انتشار
- `.github/workflows/civil-law-tree.yml`: Release gates مستقل

## مدل آموزشی ۸ درس
۱ اشخاص و محجورین
۲ اموال و مالکیت
۳ قواعد عمومی قراردادها و تعهدات
۴ مسئولیت مدنی و ضمان قهری
۵ خانواده
۶ عقود معین ۱
۷ عقود معین ۲
۸ شفعه، وصیت و ارث

مواد خارج از توالی آموزشی مستقیم (مانند ادله اثبات) با یک جایگاه اصلی و ارتباطات فرعی نگهداری می‌شوند و تا تأیید حقوقی نهایی وضعیت NEEDS_LEGAL_REVIEW دارند.
